# Eval Prompt: Combat Depth

```text
I am building a small action RPG. Combat is easy to understand, but it gets repetitive after a few minutes. I want it to feel deeper, but I do not want more buttons or long tutorials. Propose the smallest playable test before adding a big system.
```

## Good Output Should

- Identify the tradeoff between tactical depth and input/cognitive load.
- Avoid adding a large skill tree or combo system as the first prototype.
- Suggest a small playable slice using existing inputs.
- Include feedback and debug visibility.
- Include a short playtest or verification step.
