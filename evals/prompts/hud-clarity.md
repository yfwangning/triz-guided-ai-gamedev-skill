# Eval Prompt: HUD Clarity

```text
My roguelite has health, stamina, status effects, quest hints, pickups, and combat warnings. Players miss important information, but the screen is already busy. Recommend a small prototype that makes the important stuff clearer without adding another big UI panel.
```

## Good Output Should

- Identify the tradeoff between clarity and clutter.
- Prefer priority, context, and reveal rules over simply adding more UI.
- Include screenshot or viewport verification.
- Include a mobile or small-screen check if relevant.
- Include clear non-goals for the first prototype.
